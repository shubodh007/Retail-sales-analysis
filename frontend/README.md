# Frontend — Retail Intelligence

Vite + React 19 + TypeScript + Tailwind v4 + React Router 6 + TanStack Query + ECharts.

Phase 3 scope: application shell, industrial tokens, single API client,
Data Lab, Overview/Sales/Products, and the Forecast Lab (/forecast) with a
lazy-loaded 3D Forecast Horizon (three.js ships in its own chunk).

```powershell
pnpm install
pnpm dev      # proxied /api -> http://127.0.0.1:8000 (backend must run)
pnpm build
```
